# 冷门信息挖掘机 · cold-mining

AI 每个工作日 09:40 自动挖一个你平时很少接触的冷门领域，产出一份**外行人也能看懂、图文并茂**的入门报告（单文件离线 HTML）。

- 风格：暗色 + 金色点缀，统一模板，内联 SVG 插画 + 图表，不依赖网络。
- 主题池：拍卖行捡漏、域名投资、球鞋碳板、老相机行情、威士忌投资、碳信用……一年积累几十个领域的常识。
- 在线浏览：https://raychan611.github.io/cold-mining/
- 每日报告：见 `reports/` 目录，或落地页 `index.html`。
- 模板：本仓库根目录 `template.html`（含「域名投资」示例）。

> ⚠️ 内容由 AI 基于公开信息整理，仅供参考，不构成任何投资或消费建议。
